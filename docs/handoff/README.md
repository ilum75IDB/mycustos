# docs/handoff/

Recap strutturati delle sessioni di lavoro, generati dalla skill `/handoff`
(`HANDOFF_YYYY-MM-DD[-NN].md`). Si leggono a inizio sessione con `/handoff-read`.
Sono pubblici: documentano decisioni e stato di avanzamento del progetto, quindi non devono
contenere riferimenti a clienti, hostname, IP, path o credenziali reali.

## Storico

> Ordine **cronologico inverso**: l'handoff più recente è la prima riga della tabella.
> Per una giornata con più handoff, quello valido è quindi il **più in alto** della catena `↳ supersede`.

| File | Tema sintetico |
|---|---|
| [`HANDOFF_2026-10-23.md`](HANDOFF_2026-10-23.md) | Rilasci v0.1.0 (F0) e v0.2.0 (F1: auth, preflight, check-config, config show) |
