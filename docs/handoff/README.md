# docs/handoff/

Recap strutturati delle sessioni di lavoro, generati dalla skill `/handoff`
(`HANDOFF_YYYY-MM-DD[-NN].md`). Si leggono a inizio sessione con `/handoff-read`.
Sono pubblici: documentano decisioni e stato di avanzamento del progetto, quindi non devono
contenere riferimenti a clienti, hostname, IP, path o credenziali reali.
